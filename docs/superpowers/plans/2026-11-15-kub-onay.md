# KÜB Doz/Arınma + Hekim Onayı Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ruhsatlı ürünlerin KÜB 4.9 (doz) ve 4.11 (arınma) bölümlerini kelimesi kelimesine uygulamaya almak, sığır arınma sayılarını otomatik okumak ve hekimin sohbetten verdiği hastalık onayını kaydeden araçları eklemek.

**Architecture:** `scripts/kub-indir.mjs` PDF'leri bir kez indirir (git dışı klasöre); `scripts/kub-ayikla.mjs` `pdftotext` ile metni çıkarır, bölümleri ve arınmayı `lib/kub.js` saf fonksiyonlarıyla ayrıştırıp `veri/kub.json` üretir. Ekranlar `veri/kub.json`'u etken ve (onaylı) hastalık sayfasında gösterir. `scripts/onayla.mjs` onay kaydını yazar.

**Tech Stack:** Mevcut: düz HTML + ES modülleri, `node --test`, Playwright. Betikler için sistem aracı `pdftotext` (Poppler; bu makinede `/mingw64/bin/pdftotext`).

**Spec:** `docs/superpowers/specs/2026-11-14-vet-defter-design.md` (§15 ek bu planın dayanağı)

## Global Constraints

- Mevcut Global Constraints (`docs/superpowers/plans/2026-11-14-vet-defter.md`) aynen geçerli.
- KÜB metni **kelimesi kelimesine**; yalnız satır sonu birleştirme / fazla boşluk temizliği. Yapay zekâ yeniden yazımı yok.
- Bakanlık sitesine istekler sıralı, aralarında ≥ 2,5 sn, genel User-Agent, hata/HTML yanıtında dur; yalnız `veri/urunler.json`'daki `kubUrl`'ler.
- İndirilen PDF'ler `.superpowers/kub-pdf/<urunId>.pdf` (git dışı); yeniden çalıştırmada var olan atlanır.
- Taslak hastalık sayfasında ürün/doz alıntısı yok; etken sayfasında KÜB alıntısı serbest, "KÜB'den alıntı" etiketli.
- Arınma sayısı yalnız `guven: 'yuksek'` ise etiket olarak gösterilir; her zaman yanında "KÜB'den otomatik okundu — metinle karşılaştırın".
- `sw.js` `DOSYALAR` `veri/kub.json`'u içerir; `SURUM` artar.

## Review Focus

1. **Çok türlü arınma cümlesi** ("sığır, keçi ve koyunlar 28 gün … sığırlarda 10 gün (20 sağım), keçi ve koyunlarda 7 gün") → sığır et 28, süt 10 gün = 240 saat; keçi değerleri sığıra karışmaz. Test: Task 2.
2. **"Laktasyondaki / sütü insan tüketimine sunulan ineklerde kullanılmaz"** → `sut: 'kullanilmaz'`, yüksek güven. Test: Task 2.
3. **Metinsiz (taranmış) ya da 4.9/4.11 başlığı bulunamayan PDF** → `metinYok: true`, ekranda "KÜB'e bakın" + bağlantı; çökme yok. Test: Task 2 + Task 3 e2e.
4. **Aynı ürün birden çok yol/doz** (ör. IV ve IM ayrı süreler) → güven düşük, sayı gösterilmez, metin gösterilir. Test: Task 2.
5. **Onaylı hastalık + içeriği sonradan değişti** → onay düşer, alıntı kaybolur (mevcut `onayliMi`). Test: Task 4.

### Task 2: KÜB ayrıştırma ve arınma okuma (Opus)

**Files:** Create `lib/kub.js`, `scripts/kub-ayikla.mjs`, `test/kub.test.js`, `test/ornek/kub/*.txt` (gerçek KÜB metinlerinden kısa örnekler), `veri/kub.json`, `veri/sema/kub.schema.json`; Modify `scripts/dogrula.mjs` (kub kimlikleri `urunler`'de var, şema), `lib/veri.js` (`kub` yükle), `package.json` (`"kub-ayikla"`).

**Interfaces:**
- `lib/kub.js`:
  - `export function bolumAyir(metin: string): { doz: string|null, arinma: string|null }` — `^\s*4\.9\b` başlığından `^\s*4\.10\b`'a, `^\s*4\.11\b`'den `^\s*(4\.12|5\.?)\b`'ye; başlık satırı hariç; satır sonu tirelerini/kırılmalarını paragrafa birleştir; boşsa null.
  - `export function sigirArinmasi(arinma: string|null): { et_gun: number|null, sut: { saat: number } | 'kullanilmaz' | 'belirtilmemis' | null, guven: 'yuksek'|'dusuk' }` — Review Focus 1, 2, 4. Sığır/inek/buzağı/dana/düve geçen ya da tür belirtmeyen ifadeler; gün→saat ×24; "sağım" sayısı yalnız doğrulama için.
- `veri/kub.json`: `{ cekilmeTarihi, urunler: { [urunId]: { doz: string|null, arinma: string|null, sigir: <sigirArinmasi sonucu>, metinYok: boolean } } }`.
- `scripts/kub-ayikla.mjs`: `.superpowers/kub-pdf/*.pdf` → `pdftotext -enc UTF-8` (layout'suz) → `bolumAyir` + `sigirArinmasi` → `veri/kub.json`; özet rapor (metinYok sayısı, guven dağılımı). İndirme sürerken de çalışabilir (olanları işler).
- `lib/veri.js` `veriYukle` dönüşüne `kub` eklenir (dosya yoksa `{ urunler: {} }`).

- [ ] Step 1: `test/kub.test.js`: örnek metin (Ekomisin LA, `test/ornek/kub/ekomisin.txt`) → doz "Derin kas içi yolla uygulanır…" ile başlar, arınma "Tedavi süresince…" ile başlar; `sigirArinmasi` → `{ et_gun: 28, sut: { saat: 240 }, guven: 'yuksek' }`. "sütü insan tüketimine sunulan … ineklerde kullanılmaz" → `sut: 'kullanilmaz'`. İki yol farklı süre → `guven: 'dusuk'`. Başlıksız metin → `{ doz: null, arinma: null }`. "Et: 0 gün" → `et_gun: 0` (null'dan ayrı).
- [ ] Step 2–4: FAIL → yaz → PASS; mevcut indirilmiş PDF'lerle `npm run kub-ayikla` çalıştır, `npm run dogrula` temiz.
- [ ] Step 5: Commit `feat: KÜB bölüm ayrıştırma ve sığır arınma okuma`.
